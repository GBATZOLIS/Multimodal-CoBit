\section{Method}
\label{sec:method}

We extend CoBit \citep{method:cobit} to learn a joint distribution over modalities represented
as bits. The extension has two parts: a layout that brings their representations into one
bitstream, and a training mixture in which the observed bits determine what the model must
generate. One denoiser can then generate paired observations together or complete one from the
other. We retain CoBit's diffusion process, denoiser parameterisation and scheduling rule;
our contribution is their use in a shared multimodal formulation, evaluated across domains.

\subsection{Representing modalities in one bitstream}
\label{sec:method:multimodal}

Each example is encoded as $\vx_0\in\{0,1\}^{S}$. Discrete symbols are written as binary
codes, while continuous observations first pass through a frozen tokenizer. A fixed layout \micha{What does it mean? Fixed order? Fixed order + padding per modality? If defined later say it here}
specifies where each modality appears, with truncation and padding to accommodate variable
lengths. Tokenizers and decoders are modality-specific; the denoiser operates only on their bits.

The layout can preserve different kinds of correspondence. For speech and text, we concatenate
segments of text, speaker and speech codes. Their vocabularies occupy disjoint integer ranges
and fit into a common 18-bit word. MNIST-Sum instead combines raw binary pixels with deterministic
7-bit text codes, requiring no learned tokenizer. Protein sequence and structure have a natural
residue-level alignment: we concatenate the five amino-acid bits and thirteen structure-code
bits at each residue. These are alternative ways of constructing the same binary input.

Following CoBit, we group the stream into fixed-width patches and project each patch into one
transformer position. A patch can hold a token, several symbols or aligned codes from two
modalities. All positions share one input projection, transformer trunk and bitwise prediction
head, with one-dimensional positional information. The layout supplies modality identity through
position and code assignment, without a learned modality-specific embedding. Patch widths,
encodings and budgets are specified with the experiments.

\subsection{Continuous denoising with CoBit}
\label{sec:method:cobit}

CoBit treats binary values as continuous during diffusion, applying Gaussian corruption
$\vx_\sigma=\vx_0+\sigma\bm{\epsilon}$, where
$\bm{\epsilon}\sim\mathcal N(\vzero,\mathbf I)$.
The denoiser $D_\theta(\vx_\sigma,\sigma)\in(0,1)^S$ estimates the probability that each
clean bit is one. Its logits combine an analytic isolated-bit posterior with a learned residual
that captures dependencies across the stream. Here those dependencies include both the structure
within each modality and the correspondence between modalities. Self-conditioning supplies a
previous clean estimate as an additional input; we suppress this argument in the notation.

We also reuse CoBit's online entropy-derived schedule to allocate training noise levels and
sampling steps according to the measured denoising error. All bits being generated share a
noise level, and the schedule is estimated for each checkpoint's training mixture.
Appendix~\ref{app:method} gives the parameterisation and scheduling details.

\subsection{Joint and conditional generation by partial denoising}
\label{sec:method:directions}

For each training example, we sample a task and construct a mask $M\in\{0,1\}^{S}$, with
$M_i=1$ for observed bits and $M_i=0$ for bits to generate. Observed bits remain clean:
\begin{equation}
\vx_\sigma=\vx_0+(1-M)\odot\sigma\bm{\epsilon}.
\label{eq:partial-denoising}
\end{equation}
We apply CoBit's binary score-matching objective only to the generated bits,
\begin{equation}
\Ls(\theta)\propto
\E\!\left[w(\sigma)
\left\|(1-M)\odot\bigl(D_\theta(\vx_\sigma,\sigma)-\vx_0\bigr)\right\|^2\right],
\qquad
w(\sigma)=\frac{\sigma^2+\sigma_{\mathrm{data}}^2}
{\sigma^2\sigma_{\mathrm{data}}^2},
\label{eq:loss}
\end{equation}
where $\sigma_{\mathrm{data}}=1/2$ and the expectation includes examples, tasks, noise levels
and Gaussian noise. The weighting follows EDM \citep{image:edm}; no separate loss is introduced for either modality.

Leaving all content bits unobserved trains joint generation. Observing one modality trains
generation of the other, while observing a prefix trains continuation. The mask acts on bits,
so it can select an entire segment or one channel within a protein patch. Fixed structural
markers, where used, remain observed even for joint generation. Each checkpoint is trained on
the task mixture specified for its experiment.

At inference, we initialise the unobserved bits with Gaussian noise and hold the observed bits
fixed throughout denoising. A first-order probability-flow solver updates all generated bits in
parallel, optionally with stochastic churn. Conditional sampling can use classifier-free guidance
\citep{method:cfg}, combining predictions with the observed content present and replaced by a
null value of $1/2$. Guided steps use two denoiser evaluations; unguided steps use one.
Final predictions are converted back to codes and decoded with the corresponding modality
decoder. We train a separate checkpoint for each modality pair.
