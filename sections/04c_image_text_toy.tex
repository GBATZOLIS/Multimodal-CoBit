\subsection{Image and text: a controlled proof of concept}
\label{sec:exp:imagetext}

\begin{figure}[t]
\centering
\includegraphics[width=\linewidth]{figures/mnist_sum/fig_mnist_sum_compact.pdf}
\caption{MNIST-Sum, a controlled image--text evaluation. (a) Four binarised MNIST digits and their equation form one flat sequence of 3,388 bits (3,136 pixel, 84 text and 168 marker bits); the zoom-ins show bits from the displayed pair. One denoiser serves both conditional directions by observing one part of the stream and denoising the other. (b) With nothing observed, the same weights co-generate an image and equation from noise; a pair is correct only when the generated equation matches the generated image. Rates use $n{=}4{,}096$ samples per direction; the displayed examples illustrate, but do not estimate, those rates.}
\label{fig:mnist:sum}
\end{figure}

MNIST-Sum is a controlled test of the multimodal interface, not a natural-image benchmark. Each
example pairs four binarised MNIST digits \citep{image:mnist} with their ordered equation and sum.
The model must read and add a supplied image, draw the four digits named by a supplied equation, or
generate an image and equation that agree. Neither modality uses a learned tokenizer, so there is
no reconstruction floor. Image$\rightarrow$text is scored by exact string match; image-emitting
directions are evaluated with a fixed, separately calibrated digit classifier. The task therefore
provides an unusually direct test of whether raw visual bits and symbolic text bits can share one
generative space under a modality-agnostic 1-D denoiser.


\textbf{One bitstream, no learned tokenizer.} Images enter as raw binary pixels and text uses a
deterministic 40-symbol, 7-bit code. Each pair becomes a sequence of 3,388 bits: 3,136 pixel bits,
84 text bits and 168 marker bits, grouped into 28-bit positions. The denoiser receives this
sequence and its 1-D positions, but no pixel grid, 2-D attention pattern, modality-specific
embedding, encoder or prediction head. A single 63.0M-parameter model, trained for 500K steps,
performs all three directions; only the set of observed positions changes.

\textbf{Result.} At $n{=}4{,}096$ per direction, image$\rightarrow$text is 97.56\% exact,
text$\rightarrow$image places all four requested digits correctly in 99.95\% of samples, and
joint co-generation from noise is 99.46\% mutually consistent (Figure~\ref{fig:mnist:sum}).
Held-out digit tuples reach 97.85\% image$\rightarrow$text, statistically indistinguishable from
seen tuples. The residual joint error splits roughly evenly between cross-modal disagreement and arithmetic
slips, each under 0.3\%. Figure~\ref{fig:mnist:sum} illustrates the outputs, while
Appendix~\ref{app:image:mnist} reports classifier calibration, confidence intervals and the error
decomposition. This establishes the interface in a controlled setting; natural images, learned tokenizers and open-ended outputs enter only with the speech--text (\S\ref{sec:exp:audio}) and protein (\S\ref{sec:exp:protein}) experiments.
